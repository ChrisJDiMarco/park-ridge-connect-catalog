Park Ridge Connect Support

Last updated: June 16, 2026

Park Ridge Connect is a free resident guide for Park Ridge, New Jersey. It provides local public information, weather, places, civic workflows, and a town-focused assistant.

Get Help

For app issues, feedback, incorrect place data, or feature requests, open a public support request:

Park Ridge Connect support requests

Common Notes

  • No account is required to use the app.
  • Voice input is optional; typed questions work too.
  • Place data is generated from OpenStreetMap and refreshed daily when public data sources are available.
  • If a public source is temporarily unavailable, the app uses cached or bundled public town data.
